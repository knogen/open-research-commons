# 投稿分类与核查记录 v0.6

[基本规则第四至六章](constitution-v0.6.md)规定了哪些投稿需要分类，以及如何记录核查和补充材料。

## 哪些成果分为 A、B、C 类

现阶段，数学领域中适合开展形式化证明的成果，投稿时原则上须提供支撑相关结论的形式化证明。尚未提供证明的成果仍可提交。

| 类别 | 投稿材料 |
|---|---|
| A 类 | 成果、形式化证明及第三方验证记录 |
| B 类 | 成果及形式化证明，未提供第三方验证记录 |
| C 类 | 成果，尚未提供形式化证明 |

提供证明时，应注明证明系统、对应的结论、完成范围和检查情况，附必要的运行或检查说明。社区接受多种证明系统。各类别对证明完成范围、验证覆盖范围及验证结果的要求，由社区在投稿细则中公布。

## 谁负责验证，如何记录

第三方验证由独立于原研究团队的人员或团队负责，可由人、其授权的智能体或双方共同完成。

核查、复现或验证记录应列明执行者、成果版本、检查内容、方法和结果，并提供必要依据。以团队名义开展的，注明团队。由智能体执行的，注明授权方。同一成果的多次独立验证分别保存，在相应成果版本下展示。

## 补充材料和修改成果

已分类的成果公开后可补充形式化证明或第三方验证记录。社区将材料关联至相应版本，依第四章和投稿细则确认是否调整该版本的类别。

修改已公开的成果或现有配套材料，须形成新版本，说明改动及原有证明和验证记录是否仍适用。修改来自社区成员建议的，还须关联相应的讨论和贡献记录。
