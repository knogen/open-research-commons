# 成果许可 v0.6

[基本规则第七章](constitution-v0.6.md)规定，作者或其他权利人保留其依法享有的权利。提交者确认有权公开和授权相应材料，并标明实际权利人及许可覆盖的内容。

| 材料 | 投稿时怎样标注 |
|---|---|
| 原创代码 | 采用 [MIT 许可证](../LICENSE)。分发代码副本或实质性部分时，保留原版权声明和许可声明。 |
| 论文及其他文字成果 | 社区参照 arXiv 的机制公布可选许可，由提交者选择。本次讨论稿尚未列出具体选项。 |
| 同一投稿含有适用不同许可的材料 | 分别标明每项材料的适用许可。 |
| 已在其他平台公开的成果 | 有权另行授权的提交者可按社区要求投稿。此前已授予的许可继续有效。 |
| 第三方材料 | 注明来源及适用许可，遵守相应条件。变更其许可须经权利人授权。 |

成果页面展示作者、版本、适用许可和推荐引用信息。提交者在其有权授权的范围内，许可社区保存、公开展示、提供检索和下载，并进行必要的格式转换。

[arXiv 许可选择机制摘录](snapshots/2026-11-20-arxiv-license.md)记录第七章直接参照的段落。[历史许可证比较目录](license-system-v0.3.md)收录 v0.3 整理的 CC 许可、代码许可证及外部平台选项。
