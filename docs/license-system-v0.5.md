# 成果许可 v0.5

[基本规则第七章](constitution-v0.5.md)规定按成果类型标注许可。成果页面展示作者、版本、适用许可和推荐引用信息。

| 材料 | 本版规定 |
|---|---|
| 原创代码 | 采用 [MIT 许可证](../LICENSE)。分发代码副本或实质性部分时，保留原版权声明和许可声明。 |
| 研究论文及其他文字成果 | 提交者从社区公布的选项中选择，并清楚展示许可范围及限制。本次讨论稿尚未列出具体选项。 |
| 已在其他平台公开的成果 | 有权另行授权的提交者可按社区要求提交，此前已授予的许可继续有效。 |
| 第三方材料 | 注明来源和适用许可，遵守原条件。变更许可须取得权利人授权。 |

提交者确认其有权公开和授权相关材料，并标明实际权利人及覆盖范围。社区获得保存、公开展示、检索下载及必要格式转换的授权。

[历次许可证比较目录](license-system-v0.3.md)列有六种 CC 许可、代码许可证和外部平台的选项，可供查询。该目录记录 v0.3 当时的制度和比较材料。
