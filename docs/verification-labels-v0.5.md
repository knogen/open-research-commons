# 投稿分类与核查记录 v0.5

[基本规则第四、五、六章](constitution-v0.5.md)规定了分类的适用对象、核查记录的内容和更新方式。

## 投稿类别

对于数学等适合形式化表达和证明的研究成果，按本次投稿提供的材料分类。

| 类别 | 本版本的材料 |
|---|---|
| A 类 | 成果、形式化证明及第三方验证记录 |
| B 类 | 成果及形式化证明，未提供第三方验证记录 |
| C 类 | 成果，尚未提供形式化证明 |

提交者注明所用证明系统、证明对应的结论、完成范围及检查结果，并提供必要的运行或检查说明。社区接受多种形式化证明系统。

## 谁进行了验证

第三方验证须独立于原研究团队。执行者可以是外部人员或团队，也可以是由外部主体组织或授权的智能体。每次记录注明执行者及所属或授权主体、成果版本、检查内容、方法、结果和必要依据。同一成果的多次验证分别保留，使读者能查阅每次验证的范围和结论。

## 补充材料与版本更新

成果公开后可以补充证明和验证记录。经确认符合相应要求时，调整投稿类别并保留依据。成果更新时，须说明修改内容及原有证明和验证记录是否仍然适用。每个版本按其对应材料确定类别。
